# Flow (User Journey)

1. Sign in ([UC_sign_in](use_cases/sign_in.md))
2. Onboarding ([UC_create_course](use_cases/create_course.md)): pick base language, learning language
3. FE: Enable floating window
4. FE: Capture -> OCR
5. FE: Select text
6. Analyze sentence ([UC_analyze_sentence](use_cases/analyze_sentence.md))
7. Save vocab ([UC_save_vocab](use_cases/save_vocab.md))
8. Explain sentence ([UC_explain](use_cases/explain.md))
9. View vocabs ([UC_view_vocabs](use_cases/view_vocabs.md)), edit or unsave ([UC_manage_vocab](use_cases/manage_vocab.md))
10. Flash card ([UC_flash_card](use_cases/flash_card.md))
11. Quiz ([UC_quiz](use_cases/quiz.md))
